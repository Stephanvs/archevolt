Archevolt is a headless archetype entity component system for .NET 11 and C# 15. You write components as structs and systems as C# methods. A source generator builds typed queries, bundles, modules, and schedules. The runtime handles native component storage and serial or bounded parallel execution.

The runtime has no package dependencies. The `Archevolt` package includes its generator, and generated declarations stay in your namespace and partial types.

## A system in a few lines

```csharp
using Archevolt;

[Component]
public readonly record struct Position(float X);

[Component]
public readonly record struct Velocity(float X);

public static partial class Motion
{
    [Each]
    public static void Move(scoped ref Position position, scoped in Velocity velocity)
    {
        position = position with { X = position.X + velocity.X };
    }
}
```

The generated loop calls `Motion.Move` directly for every entity that has both components. See the [Quickstart](/getting-started/quickstart) for the complete program.

## What you get

- **Typed queries.** Named queries produce concrete rows with `ref` and `ref readonly` access. Nothing is boxed or looked up by type at run time.
- **Declarative schedules.** Order systems with `Order`, `Before`, `After`, stages, and sets. The planner adds conservative ordering where access conflicts.
- **Native storage.** Components live in dense, aligned, structure-of-arrays tables, one per archetype.
- **Opt-in parallelism.** Serial execution is the reference behavior. Enable a bounded worker pool and mark eligible systems as partitioned.
- **Change tracking, resources, messages.** Track added and changed components, share resources, and send messages with independent reader cursors.
- **AOT-friendly.** The package runs under JIT, trimming, and NativeAOT.
